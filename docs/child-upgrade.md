# Upgrade an existing child installation

Use [the current generated update guide](UPDATE_EMMA.md). It contains the exact target version, source tag, copyable child-chat prompt and PowerShell command. This link stays the same across releases.

Use the child’s own account, preserve settings and pending saves, and verify the installed and fresh-chat loaded versions. Local marketplace updates and account-owned cloud plugin updates are separate supported paths; never create a duplicate as a workaround.
