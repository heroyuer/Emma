# Metrics and interpretation

Count only captured entries. `learner_turns` and `coach_turns` are speaker-labelled entry counts, not audio utterance counts. `paired_exchanges` counts learner entries immediately following a coach entry. `learner_words_approx` counts Latin word tokens; Chinese words are not reliably segmented and are excluded. `learner_characters` counts Unicode code points. `english_only_turns_approx`, `mixed_turns_approx`, `chinese_turns_approx` detect Latin and Han characters, not spoken proficiency or true language identification; other/empty-language entries are unclassified. `learner_share_of_word_tokens_approx` compares Latin tokens on both sides, not speaking time. `elapsed_seconds` requires actual valid ordered timestamps; missing times produce null. Coverage qualifies every count.

Qualitative engagement must cite actual examples/entry numbers: volunteered a detail, asked a question, used a hint, tried a new explanation, connected a reading to life. Use unassessed if missing. Do not turn response count, hesitations, accent, sentiment or model-only repetitions into motivation/confidence/mastery scores. Distinguish successful explanation with support from independent use. Day-to-day trends depend on comparable capture and task difficulty; no invented CEFR or improvement percentage.
